CH01-2 的核心比喻，是把 AI 一人公司講成一間工廠：廠房是 Agent 原生網站，人力是 Agent 員工，生產線是 Agent 工作流。這三個要素講清楚了「工廠能不能自己跑」。

但這三個要素沒回答兩個問題。

## Agent 憑什麼知道你會怎麼判斷

員工能寫文章、能回客戶——但它照什麼標準寫、照什麼語氣回？

答案是知識庫：你的品牌主張、受眾是誰、過去的判斷案例，整理成 Agent 每次執行前都會讀的文件。沒有這一塊，員工和工作流再強，產出也只是通用內容，不是「你的」內容。

這次把它加進工廠核心，叫 **Agent 知識庫**。

## 工廠的產出，怎麼真的變成錢

廠房獲客、員工生產、工作流讓一切自動運轉——這些都還只是「運作」，不等於「賺錢」。

訂閱扣款、單筆收款、分潤拆帳，這件事需要自己的機制，不能指望它「順便」發生在某條工作流裡。

這次把它加進工廠核心，叫 **Agent 營收引擎**。

## 改了哪裡

CH01-2「AI 工廠的三個要素」表格擴充成「五大核心」，新增 Agent 知識庫、Agent 營收引擎兩列，並補上兩段說明各自解決的問題。

五個核心，不是五個各自獨立的功能——少一個，工廠就有一塊撐不住：沒有知識庫，Agent 產出的是通用內容；沒有營收引擎，工廠再會生產，錢也進不了口袋。
